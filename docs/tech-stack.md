# 기술 스택

> 팀 확정 버전은 아래 "팀 확정" 표를 따른다. 확정되지 않은 프론트엔드 라이브러리는 "제안" 표에 둔다.
> 자세 인식·운동 관련 연동 방식은 담당자가 정한 뒤 [미정 항목](#미정-항목)에 채운다.

## 팀 확정

### 프론트엔드

| 구분       | 기술       | 버전        | 역할                  |
| ---------- | ---------- | ----------- | --------------------- |
| 프레임워크 | React      | 19.3.1      | 웹 UI                 |
| 언어       | TypeScript | 6.x         | 프론트엔드 개발       |
| 빌드       | Vite       | 8.3.4       | React 개발·빌드       |
| 런타임     | Node.js    | 24.x LTS    | 프론트엔드 빌드 환경  |

Node 버전은 `.nvmrc`와 `package.json`의 `engines`로 고정한다.

## 제안

팀에서 버전까지 정하지 않은 프론트엔드 라이브러리다. 확정되면 위 "팀 확정" 표로 옮긴다.

| 구분            | 선택                           | 이유                                                                                  |
| --------------- | ------------------------------ | ------------------------------------------------------------------------------------- |
| 패키지 매니저   | npm                            | 별도 설치 없이 팀원 모두 같은 환경을 쓸 수 있다                                       |
| 라우팅          | React Router                   | SPA 라우팅의 표준. 보호 라우트 구성이 쉽다                                            |
| 서버 상태       | TanStack Query                 | API 호출의 로딩·에러·캐시를 일관되게 처리한다                                         |
| 클라이언트 상태 | Zustand                        | 인증 정보 등 전역 상태가 적어서 가벼운 도구가 적합하다                                |
| 스타일링        | Tailwind CSS                   | 디자이너 없이 빠르게 화면을 만들 때 유리하다                                          |
| 차트            | Recharts                       | 주간 현황·추이 차트에 충분하고 React 친화적이다                                       |
| 테스트          | Vitest + React Testing Library | Vite와 설정이 통합된다                                                                |
| 린트·포맷       | ESLint + Prettier              | 일반적인 조합                                                                         |
| 배포            | Vercel                         | 기획서 확정 사항                                                                      |

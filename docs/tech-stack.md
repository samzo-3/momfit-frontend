# 기술 스택

> 운동·자세 분석과 무관한 프론트엔드 기술은 프론트엔드 담당자가 확정했다. 버전은 `package.json`과 맞춘다.
> 자세 인식·운동 관련 연동 방식은 담당자가 정한 뒤 [미정 항목](#미정-항목)에 채운다.

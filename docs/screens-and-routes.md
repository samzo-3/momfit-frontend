# 화면과 라우트

> 상태: **제안**. 디자인이 나오면 갱신한다. 운동·코칭 화면의 상세는 담당자가 확정한 뒤 채운다.

| 화면        | 경로                  | 인증   | 설명                                            | 상태                      |
| ----------- | --------------------- | ------ | ----------------------------------------------- | ------------------------- |
| 로그인      | `/login`              | 불필요 | 로그인                                          | 제안                      |
| 회원가입    | `/signup`             | 불필요 | 회원가입, 출산 예정일·운동 경험 등 기본 정보 입력 | 제안                      |
| 비밀번호 재설정 | `/password/reset` | 불필요 | 이메일 인증 후 새 비밀번호 설정 | 제안 |
| 랜딩 | `/` | 불필요 | 서비스 소개, 로그인 상태에 따라 시작·홈 이동 버튼 | 제안 |
| 홈 | `/home` | 필요 | 오늘의 추천 운동, 최근 기록 요약 | 제안 |
| 운동 목록   | `/workouts`           | 필요   | 운동 종류 선택                                  | 제안                      |
| 운동 모드   | `/workouts/:id`       | 필요   | 웹캠 실시간 자세 분석과 피드백                  | **미정**                  |
| 자세 배우기 | `/workouts/:id/learn` | 필요   | 스텝별 음성 코칭                                | **미정**                  |
| 운동 리포트 | `/reports/:id`        | 필요   | 운동 종료 후 점수, 횟수, 낮은 점수 스텝         | 제안 (데이터 형태는 미정) |
| 대시보드    | `/dashboard`          | 필요   | 주간 현황, 장기 추이 차트                       | 제안                      |
| AI 에이전트 | `/agent`              | 필요   | 임신 관련 Q&A, 맞춤 정보                        | 제안                      |
| 내 정보     | `/me`                 | 필요   | 프로필(임신 주차 등) 수정                       | 제안                      |

## 라우팅 규칙

- `/`는 누구나 볼 수 있는 랜딩이다. 로그인 여부와 상관없이 로그인 화면으로 보내지 않는다.
- 인증이 필요한 경로는 보호 라우트로 감싼다. 로그인하지 않았으면 `/login`으로 보낸다.
- 로그인한 사용자가 `/login`, `/signup`, `/password/reset`에 접근하면 `/home`으로 보낸다. 보호 경로에서 `/login`으로 넘어온 경우에는 로그인 후 원래 경로로 보낸다.
- 존재하지 않는 경로는 404 화면을 보여준다.

## 미정

- 운동 모드와 자세 배우기 화면의 구성, 운동 종류별 분기 방식
- 리포트에 표시할 지표와 데이터 형태
